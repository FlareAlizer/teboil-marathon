# Геймификация стенда Teboil — беговой марафон

Сайт для стенда: квизы с автоматическим начислением баллов, витрина спортивных
активностей, админ-панель оператора, лидерборд на второй экран и счётчик
посетителей за день.

Работает **локально на ноутбуке стенда**, интернет не нужен: Next.js + SQLite.

---

## Запуск на мероприятии

```bash
npm install          # один раз
npm run build        # один раз, после любых правок
npm start            # запускать в день мероприятия
```

Сайт поднимется на `http://localhost:3000`. Порт меняется в `.env` (`PORT`).

Перед первым запуском скопируйте `.env.example` в `.env` и **смените пароль
оператора**:

```
ADMIN_PASSWORD=teboil2026
```

### Экраны

| Адрес | Для кого | Устройство |
|---|---|---|
| `/` | участник | планшет-киоск на стенде |
| `/leaderboard` | зрители | телевизор / второй монитор |
| `/admin` | оператор | телефон волонтёра |

Планшеты и телефоны подключаются к тому же Wi-Fi и открывают адрес вида
`http://192.168.x.x:3000` — точный адрес печатается в консоли при запуске
(строка `Network`).

### Как поменять баллы

Все числа собраны в объекте `SCORING` в начале `src/lib/scoring.ts`:
баллы за уровни квиза, бонус за полный проход, множитель ставки, баллы
фото-квиза и формулы для спортивных активностей. После правки — `npm run build`.

## Игры

**Квиз с рулеткой** (пункт 1 презентации) — два варианта на выбор. Колесо
крутится перед каждым из трёх уровней и показывает только те темы, где на этом
уровне остались вопросы. Перед уровнями 2 и 3 участник может поставить призы:
ставка удваивает баллы уровня, но при неверном ответе **призы сгорают, а
набранные баллы остаются**. Прохождение всех трёх уровней — главный приз и бонус.

**Угадай по фото** (пункт 2) — вопросы заводит оператор во вкладке «Фото»
админки: загружает картинку, пишет вопрос и четыре варианта, отмечает верный.
Пока вопросов нет, участник видит понятную заглушку.

**Спортивные активности** (пункты 4.1 и 4.2) — только витрина с правилами.
Баллы за чеканку, полосу препятствий, гол и дартс ставит **оператор вручную**:
система предлагает число по формуле, но оператор может его изменить.

Баллы за квизы начисляются автоматически. Правильные ответы проверяются на
сервере и не попадают в браузер до ответа участника.

## Админ-панель

Вход по паролю из `.env`. Четыре вкладки:

- **Баллы** — поиск участника по кодовому никнейму (регистр и опечатки
  прощаются), выбор активности, ввод результата, начисление. Есть ручное
  начисление произвольных баллов с комментарием.
- **Игроки** — список за день, история начислений, **отмена ошибочного
  начисления**.
- **Статистика** — счётчик за день: всего участников, сколько прошло квизы,
  сколько спортивные активности, разбивка по активностям.
- **Фото** — управление вопросами фото-квиза.

Сессия живёт 12 часов; если она истечёт, оператор увидит форму входа, а не
пустой экран.

## Проверка перед мероприятием

```bash
npm start                                   # в одном окне
node scripts/smoke-test.mjs http://localhost:3000 ВАШ_ПАРОЛЬ
```

Скрипт прогоняет 42 проверки: вход и повторный вход, валидацию никнеймов,
загрузку обоих квизов, отсутствие утечки правильных ответов, защиту админских
эндпоинтов, начисление, отмену, счётчики и лидерборд. Ожидаемый результат —
`провалено 0`.

## Важные детали эксплуатации

- **Участник = его юзернейм в Телеграме.** Регистр и «собака» не важны:
  `@Running_Fox`, `running_fox` и `@running_fox` — один человек, баллы не
  теряются. Аккаунтов, паролей и входа для участников нет.
- **У кого нет юзернейма** — оператор заводит его кнопкой «+ Участник без
  юзернейма» на вкладке «Баллы» под любым именем. На киоске формат строгий
  специально: под этим именем человеку потом выдают приз.
- **Выгрузка**: вкладка «Статистика» → «Скачать таблицу за день». Файл
  открывается в Excel двойным кликом; внутри два блока — итоги по участникам
  и все начисления построчно.
- **Киоск передают из рук в руки.** На главном экране есть кнопка
  «Завершить · следующий участник» — её нужно нажимать между людьми.
- **Повторный ответ не начисляет баллы дважды** — сервер помнит отвеченные
  вопросы, обновление страницы посреди квиза не даёт накрутку.
- **База не сбрасывается между днями.** Лидерборд и счётчики считают только
  текущий день. Чтобы начать с нуля, остановите сервер и удалите папку `data/`.
